## Развертывание и запуск

Для подтягивания зависимостей выполнить:
```
pip install -r requirenments.txt
```

Для запуска приложения выполнить:
```
flask --app main run
```

Для настройки окружения копируем файл .env.example, убираем 
расширение .example и прописываем там пароль, он используется
в эндпоинте /get-data.

## Эндпоинты

### /create-session

Http-метод: POST

Описание: Создать новую сессию и вернуть её публичный идентификатор

Параметры: нет

Возвращает: json формата:
```
{
    "data": {
        "public_id": "27afe214-c0a5-4e97-8633-c23ddc836a88"
    },
    "success": true
}
```

При запросах, время между которыми меньше 10 миллисекунд, отправляется следующий ответ:
```
{
    "msg": "Too frequent create requests",
    "success": false
}
```

### /update-session

Http-метод: POST

Описание: Обновляет данные сессии

Параметры: json формата:
```
{
    "public_id": "b05ac770-846e-4870-950b-537cb961c602",
    "steps": 10,
    "is_finished": false
}
```

Возвращает: json формата:
```
{
    "data": {},
    "success": true
}
```

### /get-data

Http-метод: POST

Описание: получаем статистику по банану

Параметры: json формата:
```
{
    "password": 'c00l_password'
}
```
Пароль устанавливается в .env (см. выше)

Возвращает: json формата:
```
{
    "data": [
        [
            0,
            0
        ],
        [
            10,
            1
        ],
        [
            0,
            1
        ],
        [
            100,
            0
        ]
    ],
    "success": true
}
```
где элементы массива data - статистика по одному пользователю,
которая состоит из кол-ва нажатий (1-ый элемент) и статусом - 
завершил ли пользователей собирать банан (2-ой элемент). 
Статус представлен в виде 0 - не завершил, 1 - завершил.
